# Revenue_Gov_Platform

Revenue & Government Services Management Platform.

## Project Structure
- `backend/`: FastAPI backend service, database models, API endpoints, and business logic.
- `frontend/`: Modern web frontend application built with Vite and React/JavaScript.

## Getting Started

### Backend
1. Navigate to `backend/`
2. Install dependencies: `pip install -r requirements.txt`
3. Run dev server: `uvicorn main:app --reload`

### Frontend
1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`
